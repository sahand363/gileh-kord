# گیله‌کُرد (GILEH KORD) — Frontend

سامانه مدرن مدیریت خرید و تدارکات رستوران گیله‌کُرد توسعه‌یافته با Svelte، TypeScript، و Vite.

## ویژگی‌های پیاده‌سازی شده

- طراحی بصری منطبق با هویت تایید شده (تم رنگی سبز تیره `#173d32`، راست‌چین، تایپوگرافی تمیز).
- ذخیره‌سازی داده‌ها در **IndexedDB** با معماری Repository pattern.
- بدون داده‌های ساختگی اولیه (شروع با پایگاه داده تمیز و پشتیبانی کامل از حالت‌های خالی/Empty States).
- ثبت خرید با اعتبارسنجی ارقام فارسی و انگلیسی.
- تکمیل خودکار (Autocomplete) نام کالا بر اساس خریدهای واقعی قبلی به همراه پیشنهاد آخرین واحد مصرفی.
- آمار لحظه‌ای خریدهای روز جاری (تعداد، جمع کل، میانگین خرید).
- فیلتر تاریخچه خریدها بر اساس جستجوی نام کالا و بازه تاریخ شمسی/میلادی.
- پشتیبان‌گیری واقعی JSON و بازیابی با اعتبارسنجی ساختار داده و تاییدیه کاربر.
- قابلیت PWA و بارگذاری آفلاین (App Shell) از طریق Service Worker و Web App Manifest.
